# 漫剧智能体平台 · AI Manga Agent Platform

> 从小说到成片，九阶段全链路自动生产。手机和电脑都能用。

## GitHub Pages 在线访问

**在线地址：** https://liyouwu448-star.github.io/

## 本地使用

### 方式一：直接打开

双击 `index.html`，浏览器即可打开使用。

### 方式二：本地服务器

```bash
# 如果有 Python
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080

# 或者用 Node.js
npx serve .
```

## 功能

- **项目工作台**：项目概览、管线状态、实时日志、引擎状态
- **生产管线**：九阶段智能体工作流可视化（写小说→转剧本→人物资产→分镜→绘图→图生视频→动效音效→TTS配音→成片合成）
- **资产库**：分镜图 / 视频 / 配音 / 剧本 分类浏览
- **新建项目**：输入故事设定，配置引擎参数，启动智能体生产
- **引擎设置**：LoRA / 视频路由 / TTS / 合成 四大引擎配置
